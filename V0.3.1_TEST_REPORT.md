# IPTV Merge Manager v0.3.1 Test Report

Date: 2026-08-14

## Passed

- Python bytecode compilation for `app/` and tests.
- JavaScript syntax validation with `node --check`.
- SQLite additive migration creates `hls_proxy_enabled` and `hls_max_height`.
- Generated `master.m3u` switches enabled channels to the internal Variant Lock endpoint.
- Three-rendition HLS fixture matching the reported stream parses as:
  - 640x360 @ 921600 bps
  - 960x540 @ 2048000 bps
  - 1280x720 @ 3072000 bps
- 720p cap selects 1280x720 @ 3072000 bps.
- 540p cap selects 960x540.
- Highest mode selects the highest available rendition.
- One-variant master generation removes the unselected 360p and 540p programs.
- Media playlist rewriting converts segment and key URIs to direct absolute CDN URLs.
- All six automated unit/integration tests pass.

## Environment limitation

A live request to the external `jmp2.uk` test stream could not be completed in the build environment because outbound DNS resolution is unavailable. The supplied real-world HLS master manifest was therefore used as the integration fixture.

Docker CLI is also unavailable in the build environment, so an actual `docker build` could not be executed here. Dockerfile/Compose version references and application syntax were validated statically.
