## Runtime limitation of this build environment

The build environment does not provide Docker, so an actual `docker build` was not executed here. The host Python environment also lacks APScheduler, so the full application import was smoke-tested with that dependency stubbed; the Docker image installs all declared requirements. Outbound network access is restricted, so live provider/CDN playback could not be exercised from the build environment. The compatibility tests use the same structural failure seen in the supplied Jellyfin log: `#EXT-X-DISCONTINUITY` followed by an extensionless HLS media URL.
