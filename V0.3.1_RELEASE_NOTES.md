# IPTV Merge Manager v0.3.1 Release Notes

## Purpose

v0.3.1 is a playback-reliability patch for adaptive HLS channels that can lag, stutter, or terminate when Jellyfin/FFmpeg opens the provider's complete multi-rendition master playlist.

The triggering case exposed 360p, 540p, and 720p variants. Jellyfin selected the 720p video stream while mapping audio from the first/360p program, and FFmpeg also reported corrupt packets and a dropped rendition playlist. v0.3.1 prevents that multi-program presentation for channels where Variant Lock is enabled.

## New HLS Variant Lock

- Opt-in per channel; existing channels are unchanged after upgrade.
- Global default cap: 720p.
- Per-channel choices: global default, Highest, 1080p, 720p, 540p, 360p.
- HLS analyzer lists detected variants and the selected rendition before you enable it.
- Bulk actions enable/disable Variant Lock and set common quality caps.
- Dynamic master manifests are resolved at playback time, so expiring CDN rendition URLs are not stored permanently.
- Multiplexed A/V variants are reduced to the selected media playlist before Jellyfin receives them.
- Relative segment and encryption-key URIs are rewritten to absolute provider/CDN URLs.
- IPTV Merge Manager does **not** relay video segments; Jellyfin downloads media directly from the upstream CDN.
- Masters with separate audio groups use a one-variant mini-master so their audio group remains present.
- A 15-second default master cache reduces repeated resolver requests without retaining provider URLs long-term.
- Selected rendition requests that fail with 401/403/404/410 cause one fresh master re-resolution and retry.

## Upgrade

The SQLite migration is additive. Existing sources, channel selection, metadata overrides, groups, numbering, EPG mappings/indexes, and v0.3 resource-profile settings are preserved.

After upgrading:

1. Open the problem channel in **Channel Browser → Edit**.
2. Click **Analyze HLS**.
3. Confirm the expected variants and selected quality.
4. Enable **HLS Variant Lock for this channel**.
5. Leave quality at **Use global default** for the initial 720p cap.
6. Save the channel.
7. Refresh the Jellyfin Live TV tuner/guide or restart playback so Jellyfin reloads `master.m3u`.

## Resource impact

The feature is deliberately playlist-only. It fetches small HLS manifests and rewrites text; media segments remain direct-to-CDN. The v0.3 short-lived XMLTV workers, sequential refreshes, disk-backed guide processing, browser pagination, and resource profiles are unchanged.
